## Featured Projects

A selection of projects that represent the areas I have been exploring.

| Project | What it explores |
|---|---|
| [**SentimentScope – Transformer for Sentiment Analysis**](https://github.com/Emigbanam/Sentimentscope-Transformer-For-Sentiment-Analysis) | Implemented a GPT-style Transformer classifier in PyTorch, building the attention mechanism, Transformer blocks, and classification head from scratch. Achieved **76.25% test accuracy** on the IMDB review dataset. |
